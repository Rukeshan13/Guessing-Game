# Number Guessing Game

## About the Project
A simple Number Guessing Game developed using Python. The computer generates a random number, and the player tries to guess it.

## Features
- Random number generation
- User input
- Hints for higher or lower guesses
- Tracks the guessing attempts

## Technologies Used
- Python 3
- Random module
- Conditional statements
- Loops

## How to Run
1. Install Python 3.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Run:

```bash
python guessing_game.py
```
